# CATfeine--coffee-shop-with-cats
CATfeine — O Café dos Gatinhos

Meu primeiro projeto de HTML e CSS da faculdade — um site para uma cafeteria temática onde os visitantes tomam café na companhia de gatinhos resgatados que aguardam adoção.

📖 Sobre o Projeto
A CATfeine é um café fictício criado como trabalho acadêmico de introdução ao desenvolvimento web. O conceito une dois universos: o prazer de um bom café especial e a presença relaxante de gatos, todos disponíveis para adoção. O site apresenta o negócio, seus produtos, informações de contato e a história da cafeteria.

Tecnologias utilizadas
HTML5 — estrutura semântica das páginas
CSS3 — estilização e layout responsivo
Font Awesome 6 — ícones
Google Fonts — tipografias (Lobster, Poppins, Comfortaa, Varela Round, Open Sans)
Google Maps Embed — mapa interativo na página de contato



Como Visualizar
Por ser um projeto estático (somente HTML e CSS), não é necessário nenhuma instalação. Basta:

Clonar ou baixar o repositório
Abrir o arquivo index.html diretamente no navegador

📌 Observações

As redes sociais (facebook_fake.html, instagram_fake.html, etc.) são páginas simuladas criadas para fins didáticos.
Os scripts de formulário utilizam alert() para simular o envio — sem backend real.
Projeto desenvolvido com foco em aprendizado de estrutura HTML semântica e estilização com CSS puro.

Desenvolvido por Gislaine Rodrigues, Victor Hugo e Lyzandra Lima como trabalho da disciplina de HTML e CSS — 1º trabalho prático de desenvolvimento web na faculdade.
